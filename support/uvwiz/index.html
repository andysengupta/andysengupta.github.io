UV Wiz — Support

UV Wiz opens to one clear screen: the live UV index for where you are, shown as a big color-coded number, plus the estimated safe sun-exposure time for Indian skin (Fitzpatrick type IV–V). No sign-up, no clutter — just the information you need before you step outside.

FAQ

How does UV Wiz know my UV index?

With your permission, UV Wiz reads your approximate location and asks the Open-Meteo Air-Quality API — a free, keyless public weather service — for the current UV index at those coordinates. The reading updates when you open the app or pull to refresh.

Why does it ask for Location permission?

Location is used only to fetch the UV index for where you actually are. It's optional: if you decline, UV Wiz shows the UV index for a default city (New Delhi) so the app still works. You can change this any time in Settings → Privacy & Security → Location Services.

What is the "safe time in the sun"?

It's an estimate of how long unprotected, bare skin can stay in the sun before reaching one Minimal Erythema Dose (mild sunburn), tuned for Indian skin (Fitzpatrick IV–V). It is an educational estimate only — individual tolerance varies and it is not medical advice. Always use sunscreen and protection.

Why does the reading sometimes show a low number?

The UV index follows the sun: it's highest around midday and drops to zero at night. A low value in the evening is expected and correct.

Is there anything to buy?

No. UV Wiz is completely free, with no ads, no purchases, and no accounts.
